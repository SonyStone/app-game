# enableRichArguments

Enables codec encoding for server-function arguments that JSON cannot preserve.

## Import

```ts
import { enableRichArguments } from "@solidjs/web/server-functions/rich-args";
```

## Type signature

```ts
function enableRichArguments(): void;
```

## Examples

```ts
import { enableRichArguments } from "@solidjs/web/server-functions/rich-args";

enableRichArguments();
```
