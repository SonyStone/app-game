Что есть в оригинальном Tabs Outliner что мне нужно, и что мне не нужно

Оригинальный Tabs Outliner показывает

- Вкладки - html link and title
- Окна Windows - Window, can be renamed
- Groups Saved Window - Group, can be renamed
- Seporator - Just a line
- Note - Same as a group, I think

Tabs Outliner показывает открытые вкладики как иерархию
Новая вкладка добавляется как child к focused вкладке
