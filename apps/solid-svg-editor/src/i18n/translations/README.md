# Translations

These `.po` files are GodSVG's translations, copied unchanged from
[GodSVG's `translations/` folder](https://github.com/MewPurPur/GodSVG/tree/main/translations)
(MIT License, Copyright (c) 2023 MewPurPur and GodSVG contributors), at GodSVG commit `3ba20e71`.

The editor translates UI text whose English matches a GodSVG msgid; other text stays in English.
To update, copy the newer files over these (skip `en.po` and `GodSVG.pot`).
